# 提交物

本目录存放**最终交给老师的正式稿件**，由 `docs/` 下的 Markdown **导出生成**。

## 规则

> ⚠️ **绝对不要直接编辑本目录下的文件。**
>
> 这里的内容是生成物。手工改这里会造成两份内容逐渐分叉 —— 最后交上去的版本和
> 仓库里记录的版本不一致，而"仓库记录"正是我们的工作量证明。一旦对不上，
> 前面所有的过程记录都会失去说服力。

**唯一的工作稿在 `docs/`**，改完重新导出即可。

## 导出方法

```powershell
# 导出全部文档
.\scripts\export_docs.ps1

# 只导出某一份
.\scripts\export_docs.ps1 -Files docs\01-需求规格说明书.md
```

导出为 `.docx`，需要 [pandoc](https://pandoc.org/)。若未安装，脚本会提示安装命令：

```powershell
winget install --id JohnMacFarlane.Pandoc
```
