# 目标检测系统 TargetDetectionSystem

> 软件工程实验 · 课题九
>
> 基于开源目标检测模型的 Web 检测系统：浏览器上传图片或视频，自动框出物体并标注类别与置信度，
> 支持置信度阈值 / NMS 阈值 / 类别过滤调节，检测历史可查、结果可下载。

---

## 课题要求对照

课程对课题九的要求，以及本项目对应的实现与需求编号（详见
[`docs/需求追踪矩阵.md`](docs/需求追踪矩阵.md)）：

| # | 课程要求 | 需求编号 | 状态 |
|---|---|---|---|
| 1 | **图片检测**：上传图片，画框标出检测到的物体，显示类别和置信度 | FR-01 | 待实现 |
| 2 | **视频检测**：上传短视频，逐帧检测并输出带框的视频 | FR-02 | 待实现 |
| 3 | **参数可调**：置信度阈值、NMS 阈值、可选类别（如只看 person/car）至少能调 | FR-03 | 待实现 |
| 4 | **结果管理**：能查看历史检测记录，支持下载结果图 / 视频 | FR-04 | 待实现 |
| 5 | 从**公开数据集**选择检测任务，用轻量级模型（如 YOLOv8）在本地 CPU/GPU 完成**训练和推理** | FR-05 | 待选型 |
| 6 | 系统需包含**输入处理、核心检测、输出处理**等基础组件 | 架构约束 | 待设计 |
| 7 | 提供良好的人机交互界面，浏览器可直接使用 | FR-06 | 待设计 |

课程另有三条硬性要求，本项目通过机制而非口号来保证：

- **禁止直接使用现成代码** → 后处理（NMS / 阈值 / 类别过滤）自研，且第三方引用全部登记。
  见 [`docs/引用与第三方来源登记.md`](docs/引用与第三方来源登记.md)。
- **提交版本控制日志、调试记录、测试用例设计作为工作量证明** → 分别由
  `scripts/worklog.ps1`、[`docs/调试记录/`](docs/调试记录/)、`tests/` + 04-测试报告 产出。
- **每项任务落实到人并规定起止日期** → 见 [`docs/开发计划.md`](docs/开发计划.md)（唯一的任务表）。

## 快速开始

```powershell
# 1. 克隆（必须用 SSH 地址；https 在本机网络下不通，见 CONTRIBUTING.md 第二节）
git clone git@github.com:Ey-in/TargetDetectionSystem.git
cd TargetDetectionSystem

# 2. 一键搭建环境（创建 conda 环境 tds + 安装依赖 + 配置 git hooks）
.\scripts\setup-dev.ps1

# 3. 拉取数据集（数据集不入库，需按 data/README.md 获取地址与校验和）
.\scripts\fetch_data.ps1 -Url <下载地址> -Sha256 <校验和>

# 4. 启动（具体命令待 M2 概要设计确定 Web 框架后补充）
```

## 许可证

本项目以 **AGPL-3.0** 发布。

原因是核心检测依赖 `ultralytics`，其许可证为 AGPL-3.0，且该许可证的约束会延伸到训练产出的
模型权重。本项目作为其衍生作品采用同一许可证，避免出现"代码说 MIT、依赖说 AGPL"这种自相矛盾
的情况（答辩时会被追问）。

第三方组件清单及其许可证见 [`docs/引用与第三方来源登记.md`](docs/引用与第三方来源登记.md)。
