# 数据集目录

> **本目录下的内容不会进入 git**（`.gitignore` 已忽略，仅保留本文件）。
> 这是有意为之：数据集动辄几个 GB，提交上去会让仓库不可用。

## 为什么不用 git-lfs

GitHub 免费额度为 **1GB 存储 / 1GB·月流量**。6 个人各自克隆几轮就会耗尽，
之后仓库会直接拒绝推送 —— 这个坑一旦踩到很难挽回，所以从一开始就不用。

## 获取方式

数据集统一用脚本拉取，并**强制校验 SHA256**：

```powershell
.\scripts\fetch_data.ps1 -Url "<下载地址>" -Sha256 "<64位校验和>" -Extract
```

校验和不是形式主义：没有它，6 台机器可能拿到不同版本的数据，
然后就会出现"在我这 mAP 是 0.6，在你那是 0.4"这种极难排查的问题。

**计算本地文件的校验和：**

```powershell
Get-FileHash .\data\dataset.zip -Algorithm SHA256
```

## 选型时考虑什么

1. **规模匹配算力。** 目标是本地 CPU/GPU 上能训完的轻量级模型，
   不要选一个训一晚上还看不到结果的。
2. **类别与演示场景匹配。** 演示时用的样例图必须能被检出东西 ——
   如果类别是"飞机、轮船"，而你手头只有校园照片，演示会很尴尬。
3. **许可证清晰。** 学术用途通常没问题，但要在登记表里写明。
4. **下载可行。** 国内网络下载大文件经常失败，优先选有国内镜像的。

候选方向（仅作参考，**不要直接照抄，选型要自己论证**）：
通用目标检测数据集的一个小子集、无人机/交通场景数据集、或自行标注的小规模数据集。

> 若要**自行标注**：标注工具与标注规范也要写进本节，
> 并且需要说明标注工作由谁完成、花了多少时间 —— 这也是工作量的一部分。
