# 源代码目录

> **本目录暂时是空的，这是有意的。**

系统的模块划分（输入处理 / 核心检测 / 输出处理三个组件的具体切分、各模块的接口签名）
属于 **M2 概要设计**的产出。

如果现在就先把目录结构建好，概要设计就变成了对既有结构的追认 —— 文档只是补个手续，
评审时一问就露馅。所以：**先出设计，再建目录。**

## 建目录时请遵守

1. **三组件对应课程的硬性要求**（"系统需包含输入处理、核心检测、输出处理等基础组件"），
   目录名要能一眼看出对应关系。
2. **后处理单独成模块，且不得 import torch。**
   它由 CI 直接单测，这是我们证明"该部分为自主编写"的方式。
   见 [`../docs/引用与第三方来源登记.md`](../docs/引用与第三方来源登记.md)。
3. 模块划分确定后，同步更新：
   - [`../docs/02-概要设计说明书.md`](../docs/02-概要设计说明书.md) 第 3 节
   - [`../docs/需求追踪矩阵.md`](../docs/需求追踪矩阵.md) 的"代码位置"列
