# 推理产物目录

> **本目录下的内容不会进入 git**（`.gitignore` 已忽略，仅保留本文件）。

这里存放系统运行时产生的检测结果：带框的图片、带框的视频、临时上传文件等。
它们由程序自动生成、随时可重建，因此不该进版本库。

## 约定

| 子目录 | 内容 | 保留策略 |
|---|---|---|
| `uploads/` | 用户上传的原始文件 | 处理完成后可清理 |
| `results/` | 检测结果图 / 视频 | 与数据库中的历史记录对应，见下 |
| `tmp/` | 中间临时文件（如视频分帧） | 进程结束即清理 |

## 与数据库的关系 ⚠️

**检测历史记录存在 SQLite 里，而结果文件存在这里 —— 两者必须保持一致。**

这是拆分设计带来的经典问题，处理不好会出现"历史记录里点进去，图片不存在"。
详细设计阶段必须明确：

- 记录被删除时，对应的结果文件谁来删？
- 结果文件被手工清理后，历史记录怎么办（置为失效 / 一并删除 / 允许重新推理）？
- 演示前如果清理了本目录，历史记录页会不会全是死链？

> 这个取舍请写进 [`../docs/03-详细设计说明书.md`](../docs/03-详细设计说明书.md)
> 的数据设计一节，并在 [`../docs/04-测试报告.md`](../docs/04-测试报告.md) 中设计对应用例。
> 答辩时这类边界问题很容易被问到。
