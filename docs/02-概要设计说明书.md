## 2. 系统架构

### 2.1 总体架构

课程硬性要求系统包含**输入处理、核心检测、输出处理**三个基础组件。
本系统的划分如下（待细化）：

```
                 ┌──────────────────────────────┐
   浏览器        │           Web 层              │
   （用户）  ──► │  上传 / 参数表单 / 结果展示     │
                 └──────────────┬───────────────┘
                                │
                 ┌──────────────▼───────────────┐
                 │        输入处理组件            │
                 │  格式校验 / 解码 / 预处理       │
                 │  图片与视频统一为帧序列         │
                 └──────────────┬───────────────┘
                                │
                 ┌──────────────▼───────────────┐
                 │        核心检测组件            │
                 │  模型加载与推理（ultralytics）  │
                 │  ★ 后处理：NMS / 阈值 / 类别过滤 │
                 │    —— 自研，纯 NumPy           │
                 └──────────────┬───────────────┘
                                │
                 ┌──────────────▼───────────────┐
                 │        输出处理组件            │
                 │  画框渲染 / 视频编码 / 结果落盘  │
                 │  历史记录写入（SQLite）         │
                 └──────────────────────────────┘
```

> 待填：画出更正式的分层架构图，标注每个组件与 FR 编号的对应关系。
