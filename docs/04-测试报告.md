## 2. 测试策略

| 层级 | 范围 | 工具 | 是否在 CI 运行 |
|---|---|---|---|
| 单元测试 | 自研后处理（NMS / 阈值 / 类别过滤） | pytest | ✅ 是 |
| 单元测试 | 输入校验、路径处理 | pytest | ✅ 是 |
| 集成测试 | 图片 / 视频端到端流程 | pytest | ⚠️ 标记 `slow`，本地跑 |
| 系统测试 | 浏览器实际操作 | 手工 | ❌ |
| 验收测试 | 对照课题九要求逐条演示 | 手工 | ❌ |

**CI 只跑不依赖模型的部分**（见 `requirements-dev.txt` 的说明），这是刻意的架构约束：
它反过来保证后处理模块始终不依赖 torch。
